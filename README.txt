# Replication Code

This repository contains the R code used for the analyses reported in the manuscript 'Are Individual Beliefs, Attitudes and Sociodemographic Characteristics Associated with Preferences Regarding Secondary Use of Healthcare Data?' submitted to Sociological Methods & Research.

## Data
The analyses use data from the LISS panel, managed by Centerdata. The data are not included in this repository. Researchers can apply for access through the LISS Data Archive (https://www.lissdata.nl/), subject to its access requirements and terms of use.

## Files
- Rscript_Beliefs, Attitudes and Sociodemographic Characteristics and Data Sharing.R: R code used for the analyses reported in the manuscript.

## Requirements
R and the packages specified in the script are required to run the analyses.

## Notes
The code is provided for peer review and research transparency. Access to the underlying LISS data must be obtained independently through the LISS Data Archive.
